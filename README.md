 #Gerenciador de Tarefas em Python

#Seja bem-vindo ao meu repositório. 

Este projeto nasceu da minha vontade de praticar e solidificar a lógica de programação em Python. Criei um sistema interativo de lista de tarefas (To-Do List) direto pelo terminal, focando em dominar estruturas fundamentais que usamos o tempo todo no dia a dia de desenvolvimento, como loops (`while`), condicionais (`if/elif/else`), listas e dicionários.

---

# O que ele faz?

O programa roda de forma bem fluida no terminal e conta com um menu interativo onde você pode:
* **Adicionar Tarefas:** Digitar o que precisa ser feito e guardar na lista.
* **Listar Tarefas:** Ver tudo o que está cadastrado, acompanhado de um marcador visual de status (`[ ]` para pendente e `[X]` para concluído).
* **Concluir Tarefas:** Marcar um item como finalizado informando o número dele.
* **Excluir Tarefas:** Limpar o que não é mais necessário.
* **Sair com Segurança:** Fechar o programa quando terminar.

---

## Tecnologias e Conceitos Aplicados

* **Python 3**
* Manipulação de Coleções (`list` e `dict`)
* Estruturas de Repetição e Decisão
* Tratamento de Erros de Entrada (`try/except` para evitar que o programa quebre se o usuário digitar uma letra em vez de número)
